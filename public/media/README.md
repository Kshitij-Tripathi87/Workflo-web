# Site photography

Place these optimised WebP files in this folder (served at `/media/...`):

| File | Scene |
| --- | --- |
| `pod.webp` | 1 Exterior machine (hero), also the closing contact section |
| `portal.webp` | 2 Gateway, the camera pushes through the ring |
| `hall.webp` | 3 Execution chamber, tilt down onto the platform |
| `path.webp` | 4 Execution pathways, tracking move |
| `hero-chamber.webp` | 5 Sealed glass module, approach and lateral move |

If a file is missing, that image is simply hidden and the page falls back to its plain background.
