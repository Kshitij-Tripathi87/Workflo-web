# Site photography

Place these optimised WebP files in this folder (served at `/media/...`):

| File | Used in |
| --- | --- |
| `hero-chamber.webp` | Story scene 1, light hero |
| `portal.webp` | Story scene 2, entering the sandbox |
| `hall.webp` | Story scene 3, inside the boundary |
| `path.webp` | Story scene 4, verification station |
| `pod.webp` | Closing contact section |

If a file is missing, that image is simply hidden and the page falls back to its plain background.
