# Workflo - Autonomous Quality Engineering

A cinematic scroll-driven web experience showcasing Workflo: an autonomous quality engineering platform that verifies software in a controlled execution environment with inspectable evidence.

## Tech Stack

- **React 19**
- **Vite**
- **TypeScript**
- **Tailwind CSS v4**

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn or pnpm

### Installation

```bash
npm install
```

### Development

To start the local development server:

```bash
npm run dev
```

### Production Build

To build the project for production:

```bash
npm run build
```

The output will be generated in the `dist` directory.
